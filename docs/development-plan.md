# 2026-11-24 开发与验收安排

沿用 Spring Boot、MyBatis、MySQL 和静态 JavaScript 单页架构。以既有发布、审核、匹配、认领、交接流程为基础完成真实可运行版本。

## 职责与交付

- 总协调负责接口约定、数据库无损迁移、真实图片上传、健康检查、独立验收和集成。
- 前端 Agent 负责校园服务界面、移动适配、个人资料、图片交互、真实统计图表、空状态和错误反馈。
- 后端 Agent 负责资料和统计接口、照片关联、认领与关闭的并发事务、字段校验、隐私及回归测试。
- 环境 Agent 负责复用 Maven/JDK/MySQL，独立数据库实例、可重复启停、日志与运行说明。
- 环境完成后由独立测试 Agent 检查页面入口、数据读写、权限、异常路径与端到端流程。

## 数据约定

业务库从空表开始，仅初始化实际管理员身份，学生通过注册创建。应用列表、匹配和统计均查询数据库。集成测试使用独立测试库，浏览器测试创建的记录只存在测试库。数据库和上传文件保存在 .local 下，重启继续使用。

## 验收顺序

1. 构建及针对并发、输入和上传的测试。
2. 验证空库启动、管理员初始化、学生注册和个人资料保存。
3. 上传真实 PNG/JPEG，发布失物和拾物，审核公开，查看匹配分数和理由。
4. 提交认领，审核通过，实际交接，核对数据库状态、统计和日志。
5. 验证越权、重复认领、并发审批、重复交接、非法文件和筛选空结果。
6. 重启应用，重新登录，核对记录与照片持久化。
7. 检查桌面与手机页面，提供运行地址、测试证据和已知限制。
