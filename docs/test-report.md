# 真实运行验收记录

## 环境与隔离

验收日期为 2026 年 11 月 24 日。使用独立 MySQL 3307 实例，业务实例端口为 8080，验收实例端口为 8081，验收数据库为 `school_finding_test`。浏览器通过 Playwright Chromium 执行真实交互，接口调用直接访问 Spring Boot，数据库检查通过独立 MySQL 连接执行。

脚本在测试库创建随机学生账号、物品、认领申请和操作日志。管理员凭据、测试账号凭据及状态文件保存在被 Git 忽略的 `.local` 目录。

## 可重复验收

先启动隔离的 8081 测试实例，再在项目目录运行以下命令。

```powershell
python scripts/verify-flow.py --help
python scripts/verify-flow.py
```

只执行接口与数据库检查时运行以下命令。

```powershell
python scripts/verify-flow.py --api-only
```

完整验收后重启测试实例，运行持久化复核。

```powershell
python scripts/verify-flow.py --persistence-only
```

脚本将写入限制在 8081 验收实例。每次完整验收创建新账号，保留既有测试记录，避免覆盖其他验收结果。

## 验收范围

| 范围 | 检查方式 |
| --- | --- |
| 注册、登录与空状态 | 浏览器创建两个学生账号，独立接口核对新账号发布和认领为空 |
| 图片与信息发布 | 浏览器上传实际 PNG，发布失物和拾物，管理员审核公开 |
| 搜索与匹配 | 浏览器筛选无结果后重置，真实匹配接口返回关联物品和规则评分 |
| 认领与交接 | 浏览器填写证明与验证答案，管理员核对、通过、确认交接 |
| 本人资料 | 浏览器保存并刷新，接口及 MySQL 独立读取联系方式 |
| 移动适配 | 375 × 812 视口检查学生和管理端十个主要页面的横向溢出 |
| 会话与权限 | 浏览器退出后旧令牌失效，学生管理接口返回 403，未登录接口返回 401 |
| 隐私 | 核对公开列表、他人详情、申请人列表，确认联系方式、隐藏特征和参考答案的可见范围 |
| 输入边界 | 检查超长资料、归一化后过短用户名、缺失字段、未来/无效时间和验证问题配对 |
| 上传边界 | 检查伪图片、空文件、缺少 file 字段、超过 5 MB、他人图片与外部图片地址 |
| 并发一致性 | 同人同物重复申请、不同申请同时审批、发布者关闭与管理员审批竞争 |
| 事务与统计 | 核对撤销、关闭、重开、取消、重复交接和日志，统计数字与 MySQL 查询一致 |

## 执行记录

2026 年 11 月 24 日，完整浏览器、API 与独立数据库验收通过 70 项。重启测试实例后，资料、物品状态、认领交接和照片持久化复核通过 11 项。Java 构建与 38 项测试通过。由于 C 盘空间耗尽，测试实例的临时目录设在 D 盘后完成验收。

静态审查期间反馈并已修复的边界包括前后端类别等字段长度一致性、用户名去除首尾空格后的长度校验、超大上传和缺少 multipart 文件字段的错误响应。以上边界已进入真实接口回归。

验收脚本调试期间修正了确认框同名按钮的定位、当前路由刷新和退出后重新登录的测试步骤。

## 验证范围与运行约定

浏览器自动化覆盖 Chromium 桌面和手机尺寸视口。当前端到端图片流程使用 PNG，上传服务支持 JPEG/PNG。会话令牌保存在应用内存中，有效期为 24 小时，重启服务后重新登录。领域记录保存在 MySQL，图片保存在本地上传目录。
